{% comment %} Para o 'with contrib' funcionar, você precisará de um custom template tag para pegar um item de um queryset por chave, já que o Django não permite acesso a dicionário com chave dinâmica no template. Exemplo de custom template tag (em producao/templatetags/get_item.py): from django import template register = template.Library() @register.filter def get_item(queryset, key): try: # Assumindo que a contribuição pode ser encontrada pela fk da ordem_producao return queryset.get(ordem_producao__pk=key) except: return None {% endcomment %}
